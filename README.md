# ⚡ TECH NET APK MANAGER

Gerenciador de APK com análise técnica, ferramentas de engenharia reversa e integração com IA.

## Recursos

- 📦 Recebimento de APK pelo Telegram
- 🤖 Análise com IA
- 📋 Análise do Android Manifest
- 🔎 Busca de configurações
- 🌐 Busca de servidores, domínios e URLs
- 🔐 Análise de criptografia e ofuscação
- 🔑 Busca de referências a chaves e configurações
- 🔍 Análise de DEX/código
- 📊 Geração de relatório
- 🔨 Recompilação de APK
- ✍️ Estrutura para assinatura de APK
